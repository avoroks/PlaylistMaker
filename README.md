# 🎵 Приложение для создания плейлистов и поиска треков

Это Android-приложение позволяет пользователю находить музыкальные треки, создавать собственные плейлисты и прослушивать аудиоотрывки.

---

## 🔧 Возможности

- 🔍 Поиск музыкальных треков по запросу
- 🎧 Воспроизведение аудиофрагментов с помощью `MediaPlayer`
- ⭐ Работа с избранными треками
- 📁 Управление плейлистами:
  - создание новых плейлистов
  - редактирование названий и содержимого
  - добавление треков в плейлисты

---

## 🛠️ Технологии

- **Язык:** Kotlin  
- **Архитектура:** MVVM  
- **Асинхронность:** Coroutines, LiveData  
- **База данных:** Room  
- **Сеть:** Retrofit 
- **Медиа:** MediaPlayer  
- **Загрузка изображений:** Glide
